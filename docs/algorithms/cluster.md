# 聚类与降维（src/cluster.mjs）

> KMeans++ / GMM-EM / PCA / 层次聚类，零依赖。所有不变量可交叉验证。
> 作者：晨星

## 1. KMeans（k-means++ 初始化）

- **数学**：最小化簇内平方和 `J = Σᵢ Σₖ rᵢₖ ‖xᵢ − μₖ‖²`；Lloyd 迭代（分配→更新质心），SSE 单调不增。
- **k-means++**（Arthur & Vassilvitskii 2007）：按 `D(x)²` 概率选初始质心，避免空簇与坏初始化。
- **复杂度**：`O(N·k·d·iters)`。
- **不变量**：`inertia` 每次迭代单调不增；收敛后重分配不变；blobs(k=3) 纯度 `≥0.95`。

## 2. GMM（期望最大化）

- **数学**：`p(x) = Σₖ πₖ N(x; μₖ, Σₖ)`；EM 迭代：
  - **E 步**：责任度 `γᵢₖ = πₖ N(xᵢ;μₖ,Σₖ) / Σⱼ πⱼ N(·)`（用 `logsumexp` 稳定）
  - **M 步**：更新 `πₖ, μₖ, Σₖ` 为加权均值/协方差
- **参考**：Dempster, Laird & Rubin 1977；单调不增对数似然是 EM 定理保证。
- **坑**：协方差需加 `regCovar` 防止奇异；初值敏感。
- **不变量**：`logLikelihood` 单调不减；责任度行和 `= 1`；协方差对称半正定（Cholesky 成功）；已知参数合成数据上均值恢复误差 `< 0.3`。

## 3. PCA（主成分分析）

- **数学**：对协方差矩阵 `C = XᵀX/(N−1)` 做特征分解，取前 `k` 大特征值对应特征向量为投影方向；最大化投影方差（Pearson 1901 / Jolliffe 2002）。
- **实现**：复用 `linalg.jacobiEigen`（对称矩阵纯正交分解），保证 `VᵀV = I`。
- **复杂度**：`O(d³ + N·d²)`。
- **不变量**：`components` 正交（`VᵀV ≈ I`）；解释方差比降序且累计 `≤ 1`；重构误差随 `nComponents` 增加而下降。

## 4. 层次聚类（平均连接）

- **数学**：自底向上合并，距离 `D(A,B) = (1/|A||B|) Σ_{a∈A,b∈B} ‖a−b‖`（average linkage）。
- **不变量**：合并层级单调上升。

## 可验证不变量（selfCheck 实测 15 项全过）

KMeans SSE 单调、GMM LL 单调+责任度归一+协方差 PSD、PCA 正交+方差降序+重构误差递减、真实参数恢复、层次链单调。
